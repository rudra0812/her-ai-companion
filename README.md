# her

her is an AI companion app built for ongoing conversations. The private application lets a person create a companion, choose a conversation mode, chat, and return to earlier interactions. Its interface also presents voice and camera features. This is a project overview; the source code remains private.

## The idea
A companion should feel continuous rather than starting from zero in every chat. The app brings companion settings, conversation history and a chat interface together in one place.

## What I built
A React/TypeScript interface with onboarding, companion profiles and a signed-in chat flow backed by Supabase. The product explores different conversational modes and multimodal interactions.
